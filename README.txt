PROJECT NAME : Loan Eligibiity

DESCRIPTION: This is a python command_line loan assessment program for microfinance business.
It helps give loans to individuals and other business owners who are in need of capital.
The program evaluates a loan applicant's information to determine whether they meet the specified
eligibiity criteria before a loan is approved.

PURPOSE: This project demonstrates the use of the following Python concepts:
          Variable, Data types,
          Input and output,
          Type conversion,
          Arithemic operations,
          Conditional statement,
          Comparison operators,
          and Logical operators in python.

HOW IT WORKS:
  The applicant is asked to fill in this details:
   1. Fullname
   2. Age
   3. Employment status
   4. Montly income
   5. Requested loan amount
   6. Loan term

  When the applicant is done filling the details, 
  The python first calculates :
  Interest - The additional amount applicant must pay when returning the loan.
  Total payment - The total amount applicant must repay.
  Montly installment -  The amount applicant must pay every month to complete the total payment.

  The python command_line then evaluates applicants details against the specified loan 
  eligiblity criteria to determine whether applicant qualifies for loan.
   

LANGUAGE USED: PYTHON
